# 云端软件复刻：真实行为对照工具（第一个可执行能力）
这是 24 个能力模块中“原版与重建版对照”的受限 HTTP JSON 核心，**不是万能完整复刻器，也不是已部署服务**。

- 对明确授权的两个 HTTPS 域名，按同一测试计划依次执行 GET/HEAD。
- 比较 HTTP 状态与 JSON 响应，输出每个用例 PASS/FAIL 及合计结果。
- 禁止非白名单域名、HTTP、重定向、写请求、超过 1 MiB 的响应。
- 测试命令：在本目录运行 `python -m unittest discover -v`。
- 当前包含 10 个通过的单元/模拟双轨测试。尚未对真实第三方软件进行 E2E 测试。
- 有实际目标软件时，必须先明确合法访问权限、测试范围与允许的域名，不自动付费，不修改生产。
