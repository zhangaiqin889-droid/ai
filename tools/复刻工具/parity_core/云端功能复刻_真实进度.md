# 云端软件功能复刻：真实执行进度

## 已实现、具备代码的能力
1. `discover.py`：离线 OpenAPI JSON 解析，输出唯一 ID 功能树、权限声明、来源证据、可观察状态，并筛出可读接口测试计划。
2. `parity.py`：授权 HTTPS 域名的 GET/HEAD 状态码及 JSON 结果差异比较（已有实现，仍需更多安全强化和真实对照测试）。
3. `report.py`：把功能树与实测结果关联，输出 PASS/FAIL/NOT_VERIFIED，并强制将整软件复刻率标成 UNKNOWN。
4. `test_parity.py`、`test_discovery.py`：自带测试覆盖核心行为；测试通过与否以独立运行输出为准。

## 不能虚报
- 这不是一键完整复刻软件。没有实现原软件完整 UI、业务后端、持久数据库、自动生成与运行成品、桌面/手机原生编译等全部能力。
- 上述代码已提交 GitHub 独立开发分支；尚未部署为常驻的云端 API。
- 真正原软件与重建版的双轨 E2E 尚需在目标授权范围内执行。
- Ralph-to-Ralph 仅为候选，没有安装到此云端运行时。

## 可复现的离线命令
```sh
cd tools/复刻工具/parity_core
python discover.py example.openapi.json
python discover.py example.openapi.json --plan
python -m unittest discover -v
python -m unittest discover -p 'test_*.py' -v
```

## 安全边界
原仓库 main 与旧项目保持不变，未启动停止中的 Vercel sandbox；默认不使用收费模型、外部付费 API 或生产端点。
