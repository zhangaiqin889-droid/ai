# 软件复刻执行 Skill

## 源和边界
- 工具在当前工作仓库 `tools/复刻工具/replica-skill` 与 `tools/复刻工具/remaster`，使用 Git 子模块锁定版本。禁止自动升级为未经审核的新提交。
- 复刻目标：万兴脑图 V14。用户最终希望接入已存在的意大利语学习网站，**不要覆盖或更改该网站生产环境**。
- 不绕过登录、反编译、逆向提取私有源代码、抄袭受保护图库或复制私有 API；对闭源系统可进行独立实现的功能等效。
- 永不自动选择付费模型；缺少真实免费授权/额度时明确中止对应步骤，不生成模拟 AI 输出冒充成功。

## 真正执行的规定路线
1. 定位仓库和真实复刻环境，读取 `tools/复刻工具/replica-skill/replica-recon/SKILL.md`、`tools/复刻工具/remaster/skills/clone/SKILL.md` 和现存 `edrawmind-replica/README.md`。
2. 对照当前可合法获取的万兴脑图实际软件/公开界面/官方说明，逐页面、逐按钮和逐种文件格式记录可观察的事实、截图、状态和操作。外部页面不能访问时标 `BLOCKED`，不要自创参考数据。
3. 对原软件做功能矩阵：多布局/手绘/主题/自由节点/关系与边界/备注/资源/大纲/看板/甘特/幻灯片/模板/导入导出/AI 内容/PPT/配音/视频/存储。
4. 真实调用 `replica-architect`、`replica-backend`、`replica-build`、`replica-test`、`replica-diff` 和 Remaster CLI 相应工具（先查 `--help` 和原 SKILL.md），在独立测试分支实现，不允许空按钮与静态演示代替成品。
5. 逐个端到端测试：输入文件→编辑→生成素材/PPT/音视频→导出→打开结果→比对参考。每个功能都记录证据、未实现项和可回滚版本。
6. 只有所有目标功能通过可核实的视觉+交互+功能+内容+导出测试，才可以称为 `VERIFIED`。单元测试通过或 Skill 安装成功不代表一比一复刻。
7. 进入生产网站前，先从部署/文件/接口核查当前状态，做好备份、独立预览验收与用户批准，不覆盖老版。

## 云端 GitHub 环境限制
GitHub Actions 是短生命周期 Runner，不是常驻云 Agent。没有受授权的有效模型供应商与持久服务时仅运行安装与工具测试，不能宣称已经实现手机上随时在线执行。
