# 专业软件工程智能体｜手机 ChatGPT 实际施工验收（实验隔离分支）

这是一个**真实可运行的工程样例**，不是已完成的通用自动开发工厂。

## 当前已实现

- ChatGPT 对话负责需求分析、架构设计、编码、代码审查和操作 GitHub。
- 独立分支交付，不触碰主分支原有项目。
- HTML/JavaScript 实现移动端适配任务看板：增删、状态切换、优先级、浏览器持久化、JSON 导入导出。
- Node 原生测试框架覆盖实际数据逻辑。GitHub Actions 自动执行测试并打包产物。
- 全部示例代码不依赖付费 API 或收费模型。

## 实际查看

在目录运行 `python -m http.server 8000 -d src`，用浏览器访问本机 8000 端口；也可将 `src/` 放到任意静态 Web 托管服务。

## 验收范围与缺口

这证明“手机 ChatGPT 里提出目标→智能分析并生成真实代码→GitHub 云端运行测试→取得可运行项目”的**单次开发链路**。
不能据此宣称已经获得无人监督的长期后台 Agent、任意自然语言自动生成所有软件、自动部署生产服务、跨会话推送结果。持续自主执行需具备可用且已授权的模型推理与事件驱动服务；普通聊天无法自行在会话结束后驱动 GitHub。高风险操作必须审批。
